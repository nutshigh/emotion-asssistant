整体架构

三大模块：Android App · Node.js 后端 · Claude API

Android App (React Native)
UI 层
聊天界面 · 设置页 · 引导页
状态管理 (Zustand)
会话状态 · 用户画像缓存 · 网络状态
本地存储 (SQLite)
聊天记录 · 用户画像 · 设置
API Client
HTTP 请求封装 · SSE 流式接收
Node.js 后端 (Express + TypeScript)
API 路由层
POST /chat · GET /profile · POST /profile/sync
核心服务层
对话服务 · 画像引擎 · Prompt 构建器
Claude API 代理
API Key 管理 · Prompt Caching · 流式转发
后端存储 (PostgreSQL / Redis)
用户画像备份(可选) · 会话缓存 · 用量统计
Claude API
System Prompt
人格定义 + 用户画像注入
Messages
对话历史 + 当前消息
Prompt Caching
画像 + 历史前缀缓存，降低成本

关键设计决策

  • 画像存在用户设备 SQLite，后端只在处理请求时暂用，不持久化敏感画像
  • Prompt Caching 是成本关键 — 将用户画像和对话摘要缓存在 Claude API 侧，避免每次请求都重复传输大量上下文
  • 流式 SSE 从 Claude API 直通客户端，减少首字延迟
  • 后端可部署在轻量云服务（Railway / Fly.io / 阿里云函数计算）
